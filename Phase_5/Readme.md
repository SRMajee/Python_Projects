# Phase_5: Advanced Data Structures

Covers high-performance algorithmic primitives: strictly O(1) LRU & LFU dual-layer caches and consistent hashing rings with virtual nodes.

## Projects in this Phase

### 1. [O(1) LRU & LFU Cache](./lru_lfu_cache)
- **Core Concepts**: `Doubly Linked Lists, Hash Maps`
- **Target Size**: `100-150 lines`
- **Key Rules / Constraints**: Strict O(1) time complexity for get and put
- **Status**: `Completed`
- **Project Brief**: Implement a cache library with multiple eviction strategies.

### 2. [Consistent Hashing Ring](./consistent_hashing)
- **Core Concepts**: `bisect, hashing`
- **Target Size**: `100-150 lines`
- **Key Rules / Constraints**: Must handle node addition/removal gracefully
- **Status**: `Completed`
- **Project Brief**: Simulate a load balancer distributing requests to server nodes.
