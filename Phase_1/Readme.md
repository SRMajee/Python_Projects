# Phase_1: Object-Oriented Foundations

Focuses on solidifying core OOP design, abstract base classes, dataclasses, strict typing, inheritance, composition, and factory patterns.

## Projects in this Phase

### 1. [In-Memory Key-Value Store](./in_memory_kv_store)

- **Core Concepts**: `abc, dataclasses, typing`
- **Target Size**: `80-120 lines`
- **Key Rules / Constraints**: Zero external libs, strict type hints
- **Status**: `Completed`
- **Project Brief**: Build a Redis-lite with TTL and transactions.

### 2. [Parking Lot Design](./parking_lot)

- **Core Concepts**: `Inheritance, Composition, Factory`
- **Target Size**: `150-200 lines`
- **Key Rules / Constraints**: Must be easily extensible to new vehicle types
- **Status**: `Not Started`
- **Project Brief**: Design a multi-level parking lot with different spot sizes and dynamic pricing.
